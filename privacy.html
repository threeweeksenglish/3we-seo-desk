Privacy policy

Last updated: 8 November 2026

Who uses this app. 3WE SEO Desk is used only by the owner of the Three Weeks English YouTube channel, on the owner's own computer.

What it accesses. With the owner's permission it reads the owner's own YouTube channel data (video list, titles, descriptions, statistics) and YouTube Analytics reports, using the read-only permissions youtube.readonly and yt-analytics.readonly.

Where data goes. The data is stored only in files on the owner's computer. It is not sent to any server run by the app, not shared with anyone, not sold, and not used for advertising.

Google API Services. The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access. The owner can revoke access at any time at myaccount.google.com/permissions, and delete the stored files from the computer.
